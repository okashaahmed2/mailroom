# Mailroom

Mailroom is a command-line tool for one newsletter: **Datacraft Bootcamp Monthly**, for Datacraft Bootcamp students and applicants. It reads the subscribers, checks an issue, and sends it to a practice mail server.

## Rules

- Use uv for everything (running, adding packages, Python versions). Never call `pip` or `python` directly; use `uv run`, `uv add`, and so on.
- Never use a real person's email address. Use addresses at `@example.com`, and `@resend.dev` for practice sends.
- Commit and push after every step.
- The newsletter's tone is friendly and respectful, written for bootcamp students.
- Every commit message is in English and says clearly what changed.

## How I learn

- I am new to Python. I have completed up to **13.7** of https://agentfactory.panaversity.org/building-ai-workers/programming-fundamentals/ and I update this number as I learn.
- Write only with what I have learned. If something new would really help, stop and tell me its name in one line. I decide.
- When the code uses something new, show me that piece first and ask me to predict what it does. Stay quiet while I guess. Then run it, and explain a line only when I ask.
- Keep `notes/predictions.md` in the repository.
